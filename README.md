# New Victoria Government Mod v2.1.1

対象：Victoria 3 **1.13.11 (Matcha)**。対応表示は`1.13.*`。ローカル本体1.13.11の実ファイルを基準にしています。

## 今回の修正

- 官僚制・革新・建設力の移譲を、元の支払国・受取国・枠・金額で双方向に照合。不正な記録を回収し、正当な契約の両側の効果を再構築します。
- 移譲modifierを45日間にし、有効な契約から月次更新。独立・属国化の即時検査と翌日検査も追加しました。
- 停止は元契約を根拠に許可し、対戦中も可能です。旧宗主国の回収が新宗主国の新しい移譲を消さないようにしています。
- 外交支援の固定期間を外し、従属関係を維持条件にしました。追加融資も属国支援として扱います。一般のVanilla送金条約は変更しません。
- 決断に「NVGM支援の記録を修復」「自国に関わるNVGM支援をすべて停止」を追加。独立後も使えます。
- 産業助成50種では、NVGMが新たに助成を有効化した建物だけを追跡。関係終了・所有国変更時に解除し、援助を条件に始めた助成は援助終了時にも解除します。元からの助成は追跡しません。同じ状態の繰り返し操作で独立欲求だけ増やす処理も防ぎます。
- 人口移動先を1政策につき1州に固定し、所有者・JE・遅延処理の対応を再検査。完了・中断・定期検査で古い印を撤去します。
- 企業設立25選択肢の実行直前に従属関係・対戦・企業枠・個別条件を再検査。建設企業の重複検査が化学企業を参照する誤りも修正しました。

## 旧セーブについて

**先にセーブをコピーしてください。v2.1.0以前のNVGM外交支援は、新しい支払国記録を持たないため、最初の修復・月次検査で終了します。必要な支援を再設定してください。** 一般のVanilla送金・投資条約は消しません。

元の両国と枠が識別できる移譲は継続できます。対応を復元できない旧移譲は解除します。同額の別の国を相手と推測しません。

旧版の助成には操作元の記録がなく、本人が元から有効にした助成と区別できないため一括解除しません。不要な旧助成は建物画面で確認してください。追跡はv2.1.1で新たに有効化した分からです。旧人口移動政策に有効な移動先記録がなければ失敗・後片付けし、再選択できるようにします。

## 停止・修復

「記録を修復」は正当な支援を維持し、不正な記録や失効した支援を処理します。

「すべて停止」は、自国が受ける・与えるNVGM移譲、NVGM外交支援、NVGMが新たに有効化して追跡した助成を停止します。企業設立時に付けた追跡付き助成も対象です。継続したい支援は再設定してください。他国間の支援、無関係な条約条項、元からの助成は停止対象にしません。

## 主な機能・数値

道路・病院、従属国管理、企業設立、人口移動、9指標の統計等を含みます。官僚制・革新・建設力はそれぞれ10・5・10単位で、資源ごとに15受取国枠です。

追加融資の係数0.20・0.25・0.30・0.35は維持しています。前段階が必要で複数Pactが併存するため、4段階目だけの35%という意味ではありません。各Pactの支払側収入上限は10%。最終的な支払額はゲーム内で確認してください。旧bankrollの週次obligation抽選・sway設定は移植していません。

軍事ボタンは兵舎・海軍管理局を建設予約します。海軍管理局で艦船は自動生成されません。8言語のキーを揃え、新規説明は日本語・英語、その他は英語を補っています。

## 導入

1. 旧版とセーブをバックアップし、旧版と新版を同時に有効にしないでください。
2. 配布ZIPの`New Victoria Government Mod/`をローカルMODの保存場所へ展開し、Launcherから登録してください。`.metadata/metadata.json`を含みます。
3. GitHubのソースZIPの場合は、展開したリポジトリのルートがMOD本体です。そのフォルダを登録してください。
4. 同梱の`New Victoria Government Mod.mod`は互換用テンプレートです。`path="mod/New Victoria Government Mod"`を配置先に合わせてください。
5. まずNVGMだけを有効にした新規ゲームで検査してください。

## Vanilla override・競合

- `common/diplomatic_actions/32_subjects_raise_payments.txt` の`raise_payments`。
- `common/diplomatic_actions/33_subjects_decrease_payments.txt` の`decrease_payments`。
- `gui/diplomatic_overview.gui`、`gui/ingame_hud.gui`。
- `gfx/map/city_data/city_types/`の10都市タイプ。

支払増減は1.13.11の実定義を基準に、全額免除との相互排他、従属関係の維持条件を追加し、軽減の固定期間を除去しました。同じ外交支援・GUI・都市タイプを変更する他MODと競合する可能性があります。

on_actionは独自処理をappendする方式です。`replace_path`は使用していません。本体のファイルは変更しません。
