# New Victoria Government Mod 2.3.0

対象：Victoria 3 1.13.*。実機確認環境：1.13.11。

## 操作

外交 → 従属国 → 各国カードの「移譲・助成の条約を作成」から条約を作成します。
条項一覧から建設力・行政力・革新の移譲、または産業助成協定を選びます。
能力の移譲は数量を直接入力します（1～10000）。助成は業種を選択します。
提供国は宗主国、受取国はその直接の従属国です。条約の成立には相手国の受諾が必要です。
助成費用は従属国が負担します。資金を支援する場合は標準の「資金の提供」条項を併用してください。

## 変更

- 3種類の能力移譲と産業助成を条約へ移行。
- 旧独自資金援助、増額・再適用操作、全額補填ボタンを廃止。
- 従属国カードの幅、中央配置、折り返しを修正。
- 有効な条約から毎日両国の移譲量を再計算。属国関係喪失・条約終了後に解除。
- 能力modifierには3日間の期限を設定し、更新停止時の永続残留を防止。
- 助成管理は国の建物参照リストへ変更。建物変数には依存しません。
- 条約開始時点の既存助成を保護し、MODが開始した助成だけを終了時に解除。
- Vanillaのraise_payments/decrease_payments上書きを廃止。

## 既存セーブ

旧移譲契約は自動で新条約へ変換しません。従属国カードの解除操作で終了し、新条約を作成してください。
旧資金援助契約は維持条件を無効化しています。
旧版の助成フラグは建物scopeで保存できなかったため、過去に開始した助成の出所は復元できません。
その助成は保護して残します。不要な分は建物画面で手動解除してください。
国の所有権が変わった建物は旧国の管理リストから外し、新所有国の助成政策を変更しません。

## 制限・競合

反映は原則翌ゲーム日です。入力値は提供国の余力で制限しないため、赤字になる場合があります。
建設力の移譲は建設力加算値、行政力は行政力加算値、革新は週次革新加算値を移動します。
建設費・助成実費の自動補填はありません。
GUI上書き：diplomatic_overview.gui、ingame_hud.gui、right_click_menu.gui、treaty_draft_panel.gui、treaty_panel.gui。
これらを変更するMODとは競合します。Vanilla common定義の意図的な上書きはありません。
セーブ互換性、併合・建物削除、複数契約、マルチプレイの全組合せは未確認です。

## テスト手順

1. デスクトップの「Victoria 3 - NVGM」で起動し、新規ゲームでイギリスを選択。
2. ハノーファーとの条約に建設37、行政23、革新11を追加。助成はライ麦農場などを選択。
3. 条約成立後に数日進め、両国の能力増減と対象建物の助成を確認。
4. 数量を変更し、翌日以降の反映を確認。
5. 条約を終了し、移譲とMOD開始分の助成が解除されることを確認。
6. 別の検査用セーブで独立・宗主国変更後の解除を確認。
7. 保存・再読み込み後も条約、数量、解除状態が維持されることを確認。

元セーブの上書きは避け、別名の検査用セーブを使用してください。
