# New Victoria Government Mod v2.1.0

対象：Victoria 3 **1.13.11 (Matcha)**。2026年10月22日のローカル本体と、バイト一致を確認したVanilla資料を基準に、元MOD v1.7.8から再構築した版です。過去会話の未回収v2.0.0 ZIPは実装の基準にしていません。

## 主な変更

- 外交画面・HUDを1.13.11のVanillaへ移植。現行の条約画面・従属国操作・パネルを保持し、NVGMの従属国管理を追加しました。
- 追加融資4段階（20%・25%・30%・35%、各段階で支払国収入の10%上限）は維持。現行Vanillaの送金条約が宗主国側から対象国へ支払われていることを起点とします。前段階を解除すると後続段階も維持条件を満たさなくなります。旧bankrollの週次obligation抽選・sway設定は移植していません。
- 助成で使う援助判定と、統計の投資権判定を現行条約へ接続しました。条約の向きと支払国の破綻・履行状態を確認します。
- 全額免除は固定の「収入移転率-30%」をやめ、対象従属国への `country_overlord_income_transfer_mult = -1` に変更。元から納付率が低い国への逆送金を避けます。支払増額・軽減とは相互排他です。
- 官僚制・革新・建設力は、それぞれ10・5・10単位を追加します。資源ごとに最大15受取国枠です。受取国と元の宗主国を紐付け、解除、独立、宗主国変更時に回収します。併合・消滅等の取りこぼしは月次で検査します。
- 軍事拡張ボタンは、建設可能な州1か所に兵舎または海軍管理局を国費で建設予約します。海軍管理局を作っても艦船は自動生成されません。
- 統計の更新をdebug console経由のイベントから通常のSGUI実行へ変更。9指標のランキング、空リスト・ゼロ除算、順位参照の取り違え、GUI式の括弧を修正しました。
- 企業設立イベントは、選択した国をsaved scopeで引き継ぐよう変更。scopeを消す順序と小麦分岐の助成先を修正しました。人口移動は候補scopeの存在を検査します。
- 病院・道路を保持。都市タイプは現行定義へ戻し、日本式・バルカン式を含む10都市タイプへ病院の表示を追加しました。現行のDLC条件・地域条件・軍事建物等の表示割当を維持しています。
- 二重script value、Vanillaと重複するmodifier type、日本語キーの重複を整理。8言語のキーを揃え、不足分には英語fallbackを補いました。未接続の試作定義・開発用生成物は配布物から外しました。

## 導入

1. 旧版を別の場所にバックアップしてください。旧版と新版を同時に有効にしないでください。
2. ZIPの `New Victoria Government Mod/` をローカルMODの保存場所へ展開し、Launcherからそのフォルダを登録してください。`.metadata/metadata.json`を含みます。
3. 同梱の `New Victoria Government Mod.mod` は互換用テンプレートで、`path="mod/New Victoria Government Mod"` を指定しています。別の場所に置く場合は実際の場所に合わせてください。現行Launcherの登録は`.metadata`形式を基準にします。
4. まず新規ゲームで、NVGMだけを有効にした状態から確認してください。

## Vanilla override・競合

- `common/diplomatic_actions/32_subjects_raise_payments.txt` の `raise_payments`。
- `common/diplomatic_actions/33_subjects_decrease_payments.txt` の `decrease_payments`。
- `gui/diplomatic_overview.gui` と `gui/ingame_hud.gui`。
- `gfx/map/city_data/city_types/` の10都市タイプ定義。フランス式・インド式・日本式・バルカン式はDLC側の実定義を基準にしています。

外交action、同じGUI、同じ都市タイプを変更するMODとは競合する可能性があります。on_actionはVanillaのeffectを上書きせず、独自on_actionを追記する方式です。`replace_path`は使用していません。納付・移譲量を別MODが変える場合は計算結果をゲーム内で確認してください。

## セーブと検証範囲

この更新では旧pact・変数・GUI接続が変わるため、旧版セーブの互換性は保証しません。旧移譲modifierの残留は月次処理で掃除しますが、旧セーブは必ずコピーで試してください。

静的検査と隔離起動での初期読み込みを確認しています。新規ゲーム内の全ボタン、外交の維持・解除、イベント発火、AI、病院・道路の採算、セーブロード、MP同期、DLC未所有環境は未検証です。初期読み込みの詳細と残る警告は、同梱の検証記録を参照してください。

確認順序：新規ゲーム → 道路/病院建設 → 従属国へ送金条約 → 追加融資・助成 → 3資源の追加/再適用/解除 → 独立/宗主国変更 → 会社設立/人口移動 → 統計更新 → セーブロード。
